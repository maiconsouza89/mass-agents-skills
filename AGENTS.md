# Agent instructions for this repository

This is the Mass Solutions skills catalog: `SKILL.md` packages for AI coding agents, plus the tooling that validates, indexes, installs and publishes them.

## Map

- `skills/<name>/` one skill per folder; `_categories.json`, `_deprecated.yaml`, `_evals/negatives.yaml` are catalog files.
- `skills-registry.json` is generated by `tools/generate-registry.ts`. Never edit it by hand.
- `src/core/` shared library (frontmatter parsing, hashing, description formula, agent catalog, path safety).
- `src/cli/` the `mass-skills` installer. Bundled by esbuild into `dist/bin.js`.
- `tools/` validator, registry generator, trigger evaluator, staleness report, skill scaffolder.
- `site/` static catalog website. `DESIGN.md` at the root is the design source; `site/tokens.ts` turns it into CSS variables.
- `.claude-plugin/` marketplace and plugin manifests; the repository root is the plugin and `skills/` is its skills directory.

## Commands

```bash
npm run check                      # typecheck + validate + registry:check + tests + evals (run before every commit)
npm run validate -- <skill>        # one skill
npm run registry -- --readme       # regenerate registry and README table after any skill change
npm run eval:triggers              # precision/recall of descriptions against evals
npm run new-skill -- mass-x --category quality --owner @you --tags a,b
npm run build                      # CLI + site
```

Node 22.18+ runs the TypeScript tools directly; there is no separate compile step for `tools/` or tests.

## Rules

- Work on skills through the `mass-skill-architect` skill (install it from this repo). It encodes the contract; do not improvise frontmatter.
- Only Agent Skills standard keys at the top level of frontmatter. Company fields go under `metadata`.
- Every skill change bumps `metadata.version` and sets `metadata.reviewed` to today, updates `evals/triggers.yaml` when triggers change, and regenerates the registry.
- Keep `SKILL.md` under about 3000 tokens; long material goes to `references/` with an explicit read condition.
- Do not add runtime dependencies to the CLI. Dev dependencies stay minimal (`typescript`, `esbuild`, `yaml`, `marked`).
- Tests use `node:test`. Add or update tests next to the code you change.
- Prose in skills and docs is English. Commit messages follow Conventional Commits.
